# Yumurcak Satış Demo

Yumurcak kreş yönetim uygulamasının satış sunumlarında kullanılan tanıtım demosu.

## 🔗 Canlı Demo

**https://furukcell.github.io/Yumurcak-Satis-Demo/**

Telefondan veya bilgisayardan linke tıklayıp doğrudan açabilirsiniz, kurulum gerekmez.

## Yumurcak Nedir?

Yumurcak, kreşler için geliştirilmiş bir yönetim uygulamasıdır. Üç farklı rol için ayrı deneyim sunar:

- **Yönetici**: kreşin genel yönetimi
- **Öğretmen**: sınıf ve çocuk takibi
- **Veli**: çocuğuyla ilgili bilgilere ulaşma

## Bu Repo

Bu repo uygulamanın kendisi değil, sadece satış demosudur. Tek sayfalık statik bir sitedir (`index.html`) ve GitHub Pages üzerinden yayınlanır.

## Yerelde Çalıştırma

```bash
git clone https://github.com/furukcell/Yumurcak-Satis-Demo.git
cd Yumurcak-Satis-Demo
```

Ardından `index.html` dosyasını tarayıcıda açmanız yeterli.

## Yayın (GitHub Pages)

`main` branch'e yapılan her push, siteyi otomatik günceller. Güncelleme 1-2 dakika içinde canlıya yansır.
